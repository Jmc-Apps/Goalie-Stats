Hockey Goalie Stats v4.18

Clean fix built from v4.13:
- Removed the patched-card approach from v4.14-v4.17.
- Defence Rate is now added inside the original calcStats() report summary object.
- Defence Rate is generated by the same statCards() function as every other report stat.
- All report stat cards use the same original .stat class.
- Text is darker for readability.
- Formula:
  Defence Rate = (Total Saves + Total Angles Closed Off) / Total Shot Records
  Total Shot Records = Saves + Goals + Angle Closed Off.
