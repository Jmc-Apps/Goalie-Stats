Hockey Goalie Stats v4.31

Fixes:
- Game Heat Map Editor buttons now prime the map instead of opening the shot editor or creating a draft immediately.
- Add Save / Add Goal / Add Angle Closed Off workflow:
  1. Click the add button.
  2. Click the D Heat Map to place the shot.
  3. For Save/Goal, optionally click the Goal Box Heat Map.
  4. Click Confirm Add.
- Pressing an add button alone does not add anything to the match.
- Removed Edit / Delete Match from the Match tab.
- Removed the separate Match Periods card from the Match tab.
- Periods are now inserted into the main Match tab details area and saved to the selected match.
- Match Editor remains the only place for editing/deleting matches.
- Ordered shots and End of Period markers remain in the Match Editor.
