Hockey Goalie Stats v4.98

Match Editor shootout controls:
- Adds a dedicated Shootout section to Match Editor.
- Matches with existing shootout data show an Edit Shootout button.
- Drawn matches without shootout data show an Add Shootout button.
- Add Shootout creates the normal 5-round shootout setup on that match.
- Shootout Editor allows editing Home/Opponent result, save method, shooter, and notes per round.
- Allows adding/removing sudden-death rounds while protecting the first 5 rounds.
- Recalculates shootout score, result, Shootout Save Rate, Shootout Defence Rate, and report/stat data after saving.
- Keeps v4.97 direct Edit Shot Placement button and earlier report fixes.
