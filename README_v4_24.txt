Hockey Goalie Stats v4.24

Changes:
- Moves heat-map editing into the bottom of the Match Editor.
- Adds consolidated D Heat Map and Goal Box Heat Map for the selected match.
- Clicking a single dot on either consolidated map opens that shot in the Match Editor above.
- D heat-map and goal-box heat-map placements are edited independently.
- Existing saved points still preload and can be moved.
- Adding a new shot from the Match Editor is supported.
- When adding/editing a shot, the selected dot is shown immediately after clicking the D or goal-box map.
- Removes the separate Heat Map Editor tab button.
