Hockey Goalie Stats v4.34

Fixes:
- Match Timeline display resets/clears when the active match changes or is finalized.
- Match Timeline only displays events from the current active/selected match.
- Game Heat Map Editor dot editing now stays inside the Game Heat Map Editor.
- Clicking a heat-map dot opens an inline editor in the Game Heat Map Editor instead of jumping to the Shot Editor.
- Inline heat-map editor can:
  - change outcome
  - move D point
  - move Goal Box point where applicable
  - clear points
  - save/cancel
  - delete that heat-map shot/item
- Add Save / Add Goal / Add Angle Closed Off stays inside the Game Heat Map Editor flow.
