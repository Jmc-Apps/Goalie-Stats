Hockey Goalie Stats v4.29

Fixes:
- Match Editor no longer re-renders while clicking/typing in Edit / Delete Match, so fields can be edited.
- Save Match Changes saves Date, Home Team, Opponent, Home Goals, Opponent Goals, Result, and Periods.
- Delete confirmation field accepts typing and Delete Selected Match works after DELETE is entered.
- Match selection now syncs with the app's active goalie/match values.
- Game Heat Map Editor now reads both:
  - normal shot records from match.shots
  - older standalone heat placements from match.heatPlacements
- Previously saved/imported shot placements should populate when the match loads.
- Old unlinked heat placements are displayed on the maps with P labels.
- Add Save / Add Goal / Add Angle Closed Off still opens a draft first and does not save until Save Shot.
- Add Angle Closed Off remains yellow/gold.
- Shot reordering, Add Shot, Periods, and End of Period markers remain included.
