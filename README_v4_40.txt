Hockey Goalie Stats v4.40

Fixes:
- Removes duplicate Game Heat Map Editor placement button rows.
- Keeps one placement control area only.
- Adds separate live counts:
  - D Heat Map unplaced recorded shots
  - Goal Box Heat Map unplaced recorded shots
- D and Goal Box placement counts are independent.
- Placing a D point decreases only the D unplaced count.
- Placing a Goal Box point decreases only the Goal Box unplaced count.
- Heat-map placement updates existing recorded shots only.
- Heat-map placement does not create new shots.
- Heat-map placement does not create new timeline entries.
- D-only, Goal Box-only, and both placements are allowed.
- Old v4.36-v4.39 heat-map add functions are redirected to placement-only behaviour.
