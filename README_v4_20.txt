Hockey Goalie Stats v4.20

New feature:
- Adds a Match Editor tab.
- Select a goalie and match.
- Displays every shot in the order it was recorded.
- Click a shot to edit it with all saved fields preloaded:
  outcome, shot type, outnumbered, rebound, notes, D heat-map point, and goal-box point.
- Save changes back to the selected shot.
- Delete a selected shot if needed.
- Timeline shot labels are updated when the edited match has timeline data.
