Hockey Goalie Stats v4.42

Fixes:
- Game Heat Map Editor dots now use the actual shot outcome colour:
  - Save = green
  - Goal = red
  - Angle Closed Off = yellow
- D Heat Map unplaced counts are broken down by outcome:
  - Save
  - Goal
  - Angle Closed Off
- Goal Box Heat Map unplaced counts are broken down by outcome:
  - Save
  - Goal
  - Angle Closed Off
- Placement buttons now match the dot colours.
- Adds Remove Placement mode.
- Remove Placement clears only the clicked map point:
  - D dot clears only D placement
  - Goal Box dot clears only Goal Box placement
- Remove Placement does not delete the shot.
- Remove Placement does not remove the shot from timeline or reports.
- Placement still updates existing recorded shots only.
- Placement does not create new shots or timeline entries.
