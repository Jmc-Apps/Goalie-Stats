Hockey Goalie Stats v4.37

Fixes:
- Match Editor now has an Add Shot button in the shot/order section.
- Add Shot opens a Match Editor draft editor with:
  - Save / Goal / Angle Closed Off
  - 1st Shot / Rebound
  - Shot Situation
  - Out Numbered
  - Rebound Result
  - Notes
  - D heat-map point
  - Goal-box point where applicable
- New Match Editor shots save once into:
  - match.shots
  - match.orderItems
  - match.timeline
  - heat maps
- Match tab Save Shot and Save Shot Without Heat Map now use a one-shot lock and duplicate-signature guard.
- Recording one shot should now create exactly one shot record.
- Duplicate order/timeline references are cleaned.
- Deleting one shot by ID in Match Editor deletes only that one selected shot.
