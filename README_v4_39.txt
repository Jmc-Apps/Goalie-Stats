Hockey Goalie Stats v4.39

Fixes:
- Restores Add Shot button in Match Editor.
- Restores Add End of Period button in Match Editor.
- Adds End of Period button in the Match tab near the shot outcome controls.
- Game Heat Map Editor is now placement-only:
  - It does not create new shots.
  - It does not add new timeline items.
  - It places D and/or Goal Box points onto existing recorded shots.
  - D-only, Goal Box-only, or both are allowed.
  - It does not allow more placed shots than recorded shots.
- Existing shots with heat-map points count as already placed.
- Timeline/report dedupe from v4.38 is preserved.
