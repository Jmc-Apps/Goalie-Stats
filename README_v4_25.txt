Hockey Goalie Stats v4.25

Fixes:
- Match Editor no longer requires D or Goal Box heat-map placement to save shot changes.
- If a shot already has saved heat-map points, they preload and can be moved.
- If a shot has no heat-map points, details can still be edited and saved.
- Game Heat Map Editor uses the same map assets/style as the individual shot editor maps.
- Game Heat Map Editor now renders all previously saved match shot placements:
  - D Heat Map shows shots with dX/dY.
  - Goal Box Heat Map shows Save/Goal shots with gX/gY.
- Clicking a dot on the consolidated map opens that exact shot for editing.
- D Heat Map and Goal Box Heat Map placements are edited independently.
- Adding a new shot from Match Editor still opens the editor; clicked dots show immediately.
