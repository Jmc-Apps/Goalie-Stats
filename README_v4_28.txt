Hockey Goalie Stats v4.28

Changes:
- Moved Edit / Delete Match controls into the Match Editor tab.
- Added match Periods field to Match and Match Editor.
- Added Period Markers management in Match Editor:
  - Add End of Period Marker
  - Auto Add Missing Period Markers
  - Clear Period Markers
  - Edit marker period and after-shot position
- Added Shot Editor Add Shot button.
- Game Heat Map Editor Add Save / Add Goal / Add Angle Closed Off now creates an editable draft first.
  It does not add a shot to the match until Save Shot is clicked.
- Add Angle Closed Off button is yellow/gold.
- Added shot reordering controls in Match Editor.
- Game Heat Map Editor reads multiple saved/imported coordinate formats and should populate on match load.
- Heat-map placement remains optional when saving edited shots.
