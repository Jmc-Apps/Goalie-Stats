Hockey Goalie Stats v4.44

Clean-up build:
- Removes the old broken v4.39-v4.43 Game Heat Map Editor scripts.
- Removes duplicate old placement controls and count blocks.
- Keeps one clean Game Heat Map Editor control section.
- Placement controls:
  - grey by default
  - Save turns green only when selected
  - Goal turns red only when selected
  - Angle Closed Off turns yellow only when selected
  - Remove Placement turns orange only when selected
- Placement buttons disable when there are no unplaced shots left for that outcome on either map.
- Clicking a heat map after choosing a placement saves a dot onto an existing recorded shot.
- D and Goal Box counts update independently by outcome.
- Remove Placement removes only the clicked placement, not the shot/timeline.
- Match tab End of Period button is restored.
- Match tab shot outcomes are preserved as Save, Goal, or Angle Closed Off.
