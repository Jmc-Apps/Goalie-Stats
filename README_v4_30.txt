Hockey Goalie Stats v4.30

Fixes:
- Removed duplicated old/bottom Match Editor sections.
- The Match Editor tab now has one clean editor flow.
- End of Period markers now appear in the same ordered list as shots.
- End of Period markers can be moved up/down like shots.
- The combined shot/period order is saved in match.orderItems and reflected in timeline ordering.
- Shot/map editor now uses the same button-style options as the Match section Record Shot screen:
  - Save, Goal, Angle Closed Off
  - 1st Shot, Rebound
  - None, Penalty Corner, Penalty Stroke, In Game 1v1, 8 Second 1v1, Own Goal, Other
  - Not Out Numbered, 2 vs 1, 3 vs 1, 4+ vs 1
  - No rebound, Safe, Dangerous
- Add Angle Closed Off remains yellow/gold.
- Add Save / Add Goal / Add Angle Closed Off still creates an editable draft first.
